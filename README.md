# Pokédex Estática com HTML e CSS 🐱‍👤

Este é um **projeto escolar** que simula uma **Pokédex**, desenvolvido usando **HTML5 e CSS3**, sem uso de JavaScript ou APIs. Cada Pokémon é representado por uma **página HTML individual**, com imagem, nome e estilo visual inspirado no universo Pokémon.

O objetivo principal foi praticar **estruturação de páginas HTML**, navegação entre arquivos e organização de conteúdo.

---

## 📁 Estrutura do Projeto

- `index.html`: Página inicial com links para os Pokémons
- Várias páginas `nome-do-pokemon.html`, como:
  - `pikachu.html`
  - `bulbasaur.html`
  - `charizard.html`
- Pasta `assets/` com imagens ou arquivos de apoio

---

## 🔍 Funcionalidades

- Navegação entre páginas HTML para cada Pokémon
- Layout visual simples e temático
- Organização em múltiplos arquivos

---

## 🧪 Tecnologias Utilizadas

- HTML5
- CSS3
